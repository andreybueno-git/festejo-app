# AdminEstoque

Arquivo: `src/pages/admin/AdminEstoque.tsx`
Rota: `/admin/estoque`

## O que faz

CRUD de embalagens + ajuste de estoque.

## Features

- Listar embalagens ativas
- Adicionar embalagem (nome, emoji, estoque inicial, mínimo)
- Editar / desativar
- Entrada/saída de estoque
- Alerta visual quando `estoqueAtual <= estoqueMinimo`
