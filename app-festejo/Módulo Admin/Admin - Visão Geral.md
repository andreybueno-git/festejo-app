# Módulo Admin — Visão Geral

Telas usadas pelo administrador do festejo.

## Telas

- [[Módulo Admin/AdminLogin]] — senha única
- [[Módulo Admin/AdminDashboard]] — home com pedidos pendentes, KPIs, sininho
- [[Módulo Admin/AdminBarracas]] — CRUD de barracas, distribuição de embalagens
- [[Módulo Admin/AdminEstoque]] — CRUD de embalagens, entrada/saída
- [[Módulo Admin/AdminConfig]] — senha, código de acesso, push, logout forçado

## Navegação

`BottomNav tipo="admin"` → 4 ícones: Dashboard, Barracas, Estoque, Config.

## Permissões

Admin enxerga e modifica tudo. Não há níveis de permissão.
